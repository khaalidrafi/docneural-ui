  1. 13.3.20 Secrets Home Services

    The (gnu home services secrets) module provides services pertaining to storing secrets, notably including password managers.

  2. Himitsu Services

    Himitsu is a daemon for storing arbitrary secrets encrypted by a single password. The daemon operates alongside a prompter, which asks the user for permission when an application requests a secret, and for the store password on first use in a session. Neither Himitsu nor its underlying cryptography library have been indepednently audited.

    Variable: home-himitsu-service-type
    This service provides the main Himitsu store daemon. It will not launch unless you have a store set up - run himitsu-store -i after the service is added to your profile to create it, and then herd start himitsud to restart the service. Configuration is as follows:
    Data Type: home-himitsu-configuration :: - package (default: himitsu)
    Package to find himitsud in.
    notify-reuse (optional)
    Interpreted shell command to run on application access to an already-approved secret.
    prompter (default: (wrap-himitsu-prompter (file-append hiprompt-gtk "/bin/hiprompt-gtk")))
    Path to a prompter binary. Defaults to hiprompt-gtk, the reference implementation. If your prompter is graphical, you should pass it through the provided wrap-himitsu-prompter procedure, which will autodetect a running display to prompt on, due to the Himitsu daemon starting before the display server is online.
    extra-options (optional)
    List of extra strings or G-expressions to insert verbatim into the Himitsu configuration file. Each list element gets its own line.

    Himitsu can be used through its command-line tool hiq or through any number of supporting services, providing compatability to other applications. Git credential support may be provided simply by adding the himitsu-git package to your profile, but other such supporting services are listed below:

    Variable: home-himitsu-ssh-service-type
    This service provides an ssh-agent implementation that stores keys through Himitsu. You may interact with a running daemon through hissh-import and hissh-export.
    Data Type: home-himitsu-ssh-configuration :: - package (default: himitsu-ssh)
    Package to find hissh-agent in.
    persist (default: '(session 300 refuse))
    List of options given when prompting to allow this service access to your list of keys. The option chosen decides how long himitsu-ssh has this access. Options can be either 'session (access is retained until the daemon closes), 'refuse (access is declined and the prompter will not ask again), 'skip (ask again next use), or a numerical access timeout in seconds.
    disclose (default: '(skip session 300))
    List of options given when prompting to allow this service use of your secret keys. Has the same format as persist.
    Variable: home-himitsu-secret-service-type
    This service provides a freedesktop Secret Service implementation, allowing Himitsu to replace see gnome-keyring-service-type and see kwallet-service-type.
    Data Type: home-himitsu-secret-service-configuration :: - package (default: himitsu-secret-service)
    Package to find hisecrets-agent in.
