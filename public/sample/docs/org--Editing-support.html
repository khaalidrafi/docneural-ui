1. 13.8.5 Editing support ¶

Org Beamer mode is a special minor mode for faster editing of Beamer documents. 

#+STARTUP: beamer
C-c C-b (org-beamer-select-environment)
Org Beamer mode provides this key for quicker selections in Beamer normal environments, and for selecting the ‘=BEAMERCOL=' property.
