Exporting (The Org Manual)

Org mode includes an exporting subsystem that can transform Org documents into a variety of other formats. The format conversion is done in two steps: first, parse the document into a syntax tree; then produce the output from that tree.

Export settings

Basic export is carried out with the commands C-c C-e. Supported targets include HTML Export, LaTeX/PDF Export and plain ASCII. Code blocks are handled through the Library of Babel.

The Export Dispatcher

The export dispatcher is the interactive menu that appears when you request an export. Published output goes through Publishing.
