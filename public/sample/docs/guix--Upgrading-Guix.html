1.0.1. 2.5 Upgrading Guix

To upgrade Guix, run: 

guix pull

See Invoking guix pull, for more information.

If you installed Guix on a foreign distro with guix-install.sh, you can upgrade the build daemon by running: 

sudo -i guix pull

followed by (assuming your distro uses the systemd service management tool): 

systemctl restart guix-daemon.service

While this works for guix-install.sh, it will most likely not work if you installed Guix through the package manager of another distribution (for instance with sudo apt install guix, pacman -S guix, or similar commands) because on many distributions guix-daemon.service will only run the Guix daemon provided by the distribution.

Waiting for your distribution to provide security fixes sometimes work, but fixing security issues in the Guix package takes times for distributions because Guix doesn't backport the security fixes to the releases used by the distributions. On some distribution versions, the Guix package is never fixed.

However since Guix updates also comes with a new daemon, so you can simply configure your distribution to use the guix-daemon provided by Guix instead. The following will assume that your distribution uses systemd.

You first need to override guix-daemon.service with the following command: 

sudo install -m 644 \
     /lib/systemd/system/guix-daemon.service \
     /etc/systemd/system/guix-daemon.service

You will then need to edit /etc/systemd/system/guix-daemon.service. To do that open this file with a text editor that has root permissions: 

sudo $EDITOR /etc/systemd/system/guix-daemon.service

Then try to find a line with ExecStart=, it should look a bit like that: 

...
[Service]
ExecStart=/usr/bin/guix-daemon --build-users-group=_guixbuild
...

Then change /usr/bin/guix-daemon into /var/guix/profiles/per-user/root/current-guix/bin/guix-daemon and save the changes.

Once done you need to tell systemd that guix-daemon.service was overriden: 

sudo systemctl daemon-reload

Once done you can then update the Guix daemon in the same way than if you installed Guix with guix-install.sh: 

sudo -i guix pull
sudo systemctl restart guix-daemon.service

On Guix System, upgrading the daemon is achieved by reconfiguring the system (see guix system reconfigure).

To migrate an existing installation to the unprivileged daemon where guix-daemon does not run as root, see unprivileged-daemon-migration.
