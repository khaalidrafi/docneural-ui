# Whale R2 — Slice 7/7: edge-states — seven signature sparks

> Fresh burn (2026-11-07): 7/7 sparks landed on `deepseek/deepseek-v4.1-flash` via the
> rebuilt `zen-whale-burn.mjs` rig (13,412 tok this salvo). Same design language and perf law as
> slices 1–2.

Design language (fixed): "A HUD, not a magazine" — ink-blue black #05070e, neon cyan / magenta / electric yellow, self-hosted Electrolize / Inter / JetBrains Mono, sharp corners with one notched edge, corner brackets on focus, circuit grid + scanlines, per-source neon hue via `--dn-src`.

PERF LAW: phones run ZERO animations; desktop at most 3 ambient loops per page; `prefers-reduced-motion` renders every spark's static end-state.

| 1 | Null-Field Survey | Emptiness you can sweep with a reticle that never quite finds anything — absence given a coordinate system, not a sad illustration. | The empty state renders `.dn-empty` as a bare 48px-pitch circuit grid (CSS `repeating-linear-gradient` at 6% `--dn-src` alpha, zero canvas cost when idle) plus one `<canvas>` sized via ResizeObserver with `devicePixelRatio` clamping at 2. On `pointermove` (coalesced through a single rAF), snap to the nearest lattice node: `nx = Math.round(x/48)*48`, `ny = Math.round(y/48)*48`, then stroke a 4-arm bracket reticle of arm length `6 + 10*(1 - Math.exp(-t/180))` with `setLineDash([2,4])`, `lineWidth=1`, `strokeStyle = oklch(0.78 0.19 H / a)` where `H` reads `--dn-src`. Each rAF tick multiplies stored node alphas by 0.90 and deletes entries <0.02; when the map is empty the rAF chain returns without re-requesting, so a still pointer means a dead loop and zero GPU work. A mono caption anchored bottom-left counts `NODES SURVEYED: n` and stays pinned to `000 RESULTS`, and on first mount one 420ms linear wipe draws a single horizontal scan line across the field, once, then never again. | none (event-driven) |
| 2 | Negative Exposure Flip | The HUD feels like a camera sensor re-exposing; theme change is a physical polarity event, not a CSS crossfade. | Svelte 5 toggles `document.documentElement.dataset.theme` and sets a one-shot `--dn-flip-phase` via `$state`; an `@property --dn-wipe-x` drives a `clip-path: polygon(0 0, var(--dn-wipe-x) 0, calc(var(--dn-wipe-x) - 18vw) 100%, 0 100%)` overlay at `background: linear-gradient(115deg, transparent 46%, color-mix(in oklch, var(--dn-cyan) 22%, transparent) 49%, #fff 50%, color-mix(in oklch, var(--dn-magenta) 18%, transparent) 51%, transparent 54%)`. The wipe runs 380ms `cubic-bezier(.83,0,.17,1)` from `-20vw` to `120vw`; at 48–53% the root gets `filter: invert(.92) hue-rotate(180deg)` for exactly 90ms, producing a true photographic-negative frame before the final palette resolves. Simultaneously, `.dn-bracket` on the focused element mirrors (`transform: scaleX(-1)`) for 120ms then snaps back; a mono readout swaps `PHOTON MODE: DARK` → `NEGATIVE` → `LIGHT` with 3 stepped updates. All colors interpolate through registered `@property` `<color>` vars so the midpoint is a legal complementary hue, not a muddy blend; scanline opacity dips to 0 at the 50% mark and returns. | none (one-shot) |
| 3 | Phosphor Re-Key | The theme doesn't fade — the HUD is re-soldered, one scanline wave at a time, like a CRT swapping phosphor chemistry mid-frame. | On `data-dn-theme` toggle, read the toggle button's `getBoundingClientRect()` into `--dn-flip-x/--dn-flip-y`, mount `canvas#dn-rephosphor{position:fixed;inset:0;pointer-events:none;z-index:90;mix-blend-mode:screen}` and run ONE rAF: t=(now-t0)/520ms, clamp 0..1. The front is a diagonal line `yf(x) = lerp(originY, innerHeight+40, easeOutCubic(t)) + (x - originX)*0.28`; for every band `i` of `bandCount = min(200, ceil(innerHeight/4))` at `y = i*4`, if `y < yf(x)` stroke the OLD palette's 24px circuit grid lines (recomputed procedurally from `--dn-src` hues captured into a `Map` before the class flip) at alpha `0.30*(1-t*0.75)`; if `y > yf(x)` stroke nothing (new theme is CSS, already underneath). At the front itself, draw a 22px-wide tear: 3px checkerboard cells where `((cx^cy)&1)===0` painted in the old hue, the inverse cells skipped — XOR dither, so it reads as a rolling signal fault rather than a wipe. At t>=1, `canvas.remove()` and delete the cached palette Map; the entire effect is one-shot, event-driven, zero registered CSS animations, so the page's ambient-loop budget is untouched. | none (one-shot) |
| 4 | INK DUMP | The HUD admits it might have to exist on paper — and converts itself, quarter-tone by quarter-tone, without losing a single source's identity. | Toggling `data-epaper` on `<html>` (or hitting print) stamps a fixed `<div class="dn-inkdump">` overlay whose `mask-image` is an 8×8 Bayer tile (`background-size:8px 8px`, `mask-composite:intersect`) scaled from `0.02` to `1` over 480ms with `steps(8)` timing — quantized dot-gain, not a fade. Origin is seeded from the trigger's `getBoundingClientRect()` into `--ox/--oy` on a radial mask, so the halftone blooms out of the button you pressed. In parallel, tokens invert on a 20ms delay (`--bg:#f4f1e8`, `--ink:#111`, `--dn-src` hues collapse) while `filter:contrast(1.7) grayscale(1)` rides the app for 200ms then is stripped, leaving per-source differentiation re-encoded as repeating-linear-gradient hatch density (4/6/9/12px pitch) instead of color. Corner brackets reflow into crop/registration marks via `::before/::after` border swaps at t=300ms. At t=480ms the overlay is `display:none`; the page is a static datasheet: hairline rules, 11px JetBrains Mono, zero neon. | none (one-shot) |
| 5 | Soldermask Polarity Peel | Theme flip feels like a PCB soldermask sheet being peeled off in one hard, notched shutter—never a mushy crossfade. | In `ThemeCure.svelte`, on the `dn:theme` toggle call `document.startViewTransition(() => { root.dataset.theme = next; root.style.setProperty('--dn-src', nextHue); })`; fallback is an immediate dataset swap. ## Perf & motion budget

**1. Null-Field Survey** — loop slot: none (event-driven). Phones: Grid renders static with a single frozen bracket reticle dead-center and the `000 RESULTS` caption; no pointer listeners attached. Reduced motion: Same frozen reticle at center with the wipe suppressed — the grid and caption are the entire, already-final render.

**2. Negative Exposure Flip** — loop slot: none (one-shot). Phones: Theme swaps instantly with no overlay, no filter, and no bracket mirror; the final palette and readout land in one frame. Reduced motion: The theme swaps instantly to its static end-state, the wipe overlay is `display:none`, and the bracketed element never mirrors.

**3. Phosphor Re-Key** — loop slot: none (one-shot). Phones: Theme swaps instantly on tap — the class flips, canvas never mounts (guard `matchMedia('(min-width:900px) and (pointer:fine)')`). Reduced motion: Under prefers-reduced-motion the class flips on the next frame with no canvas at all; the end-state palette is simply the new theme.

**4. INK DUMP** — loop slot: none (one-shot). Phones: Snaps straight to the static e-paper datasheet — no mask, no blend, no filter pass. Reduced motion: Renders the final datasheet end-state in a single frame with no mask, filter, or timing.

**5. Soldermask Polarity Peel** — loop slot: none (one-shot). Phones: On phones the theme swaps synchronously with no view-transition layer, leaving the same final theme and source hue. Reduced motion: Under prefers-reduced-motion the view-transition animation is `none`, so the new theme appears as a single static swapped frame.

**6. Not-Found Sector Probe** — loop slot: none (one-shot). Phones: Static stub grid with the yellow notched cell and full crosshair trace already drawn, all labels printed. Reduced motion: Crosshair trace and edge labels appear instantly at their final state, no sweep or typing.

**7. PRESS PROOF** — loop slot: none (one-shot). Phones: Static halftone proof image with registration marks already snapped into place; no press-pass animation runs. Reduced motion: Renders the final registered halftone proof immediately with zero passes and zero nudges.

## Why it surprises

**Null-Field Survey** — The lattice is offset by 24px, so the exact visual center of the panel is a hole between nodes — the reticle can never sit where a 'no results' crosshair is supposed to sit, and users feel the miss before they can name it. Trails decay asymmetrically because older nodes are aged by index rather than by time, so dragging fast leaves a staggered comet of half-lit corners that reads as a failed search, not a toy. It is also the rare empty state that gets cheaper the longer you look at it: stop moving and the canvas goes fully inert.

**Negative Exposure Flip** — The flip deliberately passes through a full-screen negative exposure for 90ms, so neon cyan reads as hot magenta and the ink-black becomes paper-white — the interface momentarily looks like film being developed. Corner brackets mirror to the wrong corner before snapping back, implying the HUD lost orientation during polarity inversion. It turns the most ignored state in software, the theme toggle, into a calibration event you can feel in your eyes.

**Phosphor Re-Key** — Everyone ships a cross-fade; this ships a *phosphor chemistry change*, and because the old palette is reconstructed from CSS vars rather than screenshotted, it survives scroll position and re-render. The XOR checkerboard tear is the tell — it looks like the display is briefly failing to resolve its own grid. And the wave is tilted relative to the toggle you clicked, so the fault appears to radiate from your finger, not from the top of the page.

**INK DUMP** — The `steps(8)` mask makes the transition read as real halftone dot gain rather than a CSS wipe — you can almost feel the screen ruling. The neon isn't deleted when color dies: each source hue survives as a distinct hatch pitch, so a printout still tells four sources apart by texture alone. And the corner-bracket target locks quietly become printer's crop marks, reusing chrome the user already trusts for a purpose they never expected.

**Soldermask Polarity Peel** — Most theme flips crossfade every token, so the UI briefly looks like two themes are arguing; this one never blends, it shears. The notched shutter makes the old theme feel like a physical soldermask sheet, and the seam's 3-step flicker makes the edge catch only at the PCB corner cuts. It also respects the perf law by being a one-shot snapshot swap, not an ambient loop.

**Not-Found Sector Probe** — The 404 doesn't apologize — it draws a targeting reticle around an empty coordinate, which reads as the system saying 'correct address, no such place.' The empty grid flickering only at the scan head makes absence feel measurable, like a sensor reading of nothing. Most 404s hide their shame in illustration; this one salutes it with military precision.

**PRESS PROOF** — Printing the interface doesn't merely restyle it — the neon dies into one halftone ink pass, as if the whole product was always a press proof waiting for paper. The registration crosshairs snap in four discrete corrections, mimicking a press operator physically nudging plates, and a 'PROOF — NOT FOR DISTRIBUTION' stamp appears that never exists on screen. It makes the browser's most neglected moment — the print dialog — feel like the machine confessing its true substrate.
