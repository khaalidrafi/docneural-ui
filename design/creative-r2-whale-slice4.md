Design language (fixed): "A HUD, not a magazine" — ink-blue black #05070e, neon cyan / magenta / electric yellow, self-hosted Electrolize / Inter / JetBrains Mono, sharp corners with one notched edge, corner brackets on focus, circuit grid + scanlines, per-source neon hue via `--dn-src`.

PERF LAW: phones run ZERO animations; desktop at most 3 ambient loops per page; `prefers-reduced-motion` renders every spark's static end-state.

## Perf & motion budget

**1. Tension Pluck** — loop slot: none (event-driven). Phones: Edges render as static straight strokes — pointerenter is suppressed, so no pluck state is ever created. Reduced motion: One static frame: every edge at rest amplitude 0, endpoint impulse skipped entirely.

**2. Catenary Tension Weave** — loop slot: none (event-driven). Phones: Edges render once at their rest catenary sag with no springs, no standing waves and no rAF loop; taps snap a node's edges to the taut end-state for a single static frame. Reduced motion: Every edge draws at the fully taut end-state — straight, 1px sag, full --dn-src alpha, no overshoot, no standing wave, no hover response.

**3. Tension Harp** — loop slot: none (event-driven). Phones: Edges stay perfectly straight; tapping an edge toggles a static 2px `--dn-src` highlight with no curve or impulse. Reduced motion: No sine motion or node impulse occurs; a plucked edge resolves immediately to a straight neon stroke with a brief static hue emphasis.

**4. Ego Spring Recoil** — loop slot: none (event-driven). Phones: Ego node renders pinned at rest with zero spring, tap only selects, no displacement or ghost rings. Reduced motion: Ego node sits static with strain coloring disabled and edges drawn at their settled beziers, no drag integration.

**5. Load-Bearing Catenary** — loop slot: none (one-shot). Phones: Static graph with the selected node’s incident edges already drawn as final catenaries, no spring or alpha animation. Reduced motion: Catenaries and dimming snap to their exact end-state on the first frame, with zero spring, overshoot, or lerp.

**6. Mass-Cast Selection** — loop slot: none (one-shot). Phones: Edges snap directly to final sag geometry on tap, with the gradient stroke applied in a single frame. Reduced motion: Sag renders immediately at its final offset with no spring integration or overshoot, and deselect clears in one frame.

**7. Void Shoal** — loop slot: none (event-driven). Phones: Render 16 deterministically seeded frozen chevrons at 40% alpha inside graph bounds; never start RAF and ignore pointer forces. Reduced motion: Same frozen seeded end-state as phone, with no drift, wake, or alpha ramp; all motes stay visible at final clamped positions.

## Why it surprises

**Tension Pluck** — The wave obeys the data: strong edges carry the pluck two hops and shimmer across the graph, weak edges swallow it after one node — the same gesture reads as 'singing' or 'thud' depending on where you touch, so the graph's weights become audible-feeling physics rather than a label. And the tremble isn't effect-only: the impulse goes through the real node integrator, so a fat cluster visibly jostles and re-settles with its own mass.

**Catenary Tension Weave** — Everyone animates nodes; here the nodes are inert rocks and the *edges* are the instrument — their sag is data you can read at a glance, and touching one turns a slack rope into a plucked string whose harmonic is literally the relationship's weight. The overshoot inverts the curve, so an edge briefly bows the wrong way, which reads as physical recoil rather than a CSS transition. And because the whole thing settles in 420ms and then kills its rAF, the most expensive-looking moment on the page costs nothing at rest.

**Tension Harp** — A graph UI usually treats edges as pipes; here they are strings. Plucking one edge transfers momentum through shared nodes, so a stray cursor can make a far-off cluster shiver in sympathy. The canvas briefly reads as an instrument, not a diagram.

**Ego Spring Recoil** — The camera is not a camera—it is a spring, so the ego view can be yanked and the neighbor field visibly absorbs the pull by inverse distance rather than moving 1:1. Releasing doesn't just snap back; it leaves a short ghost-ring decay trail that reads as the graph exhaling, and edge hue briefly betrays mechanical strain in electric yellow before returning to its source hue. It turns a selection gesture into a physics probe: users discover edge weights by feel because heavy edges resist the shear more than light ones.

**Load-Bearing Catenary** — Most graph tools signal selection with color; here the geometry itself becomes a load readout — heavy edges pull taut while light edges droop like slack rope, making the ego network look like a suspension bridge. The sag is a numerically solved catenary, not a bezier fake, and the one-shot overshoot makes strong edges visibly twang. Users discover edge weight without labels, legends, or hover tooltips.

**Mass-Cast Selection** — It reframes selection as mass rather than highlight: the topology itself deforms, so you read connection strength as curvature before you read color. The overshoot is deliberately restricted to the nearest two edges, making the graph feel locally elastic but globally rigid — a physical lie that improves legibility. Because the sag is distance-falloff, two nodes one hop apart can produce visibly different fabrics depending on the rest of the field, which quietly exposes graph structure you did not ask about.

**Void Shoal** — They avoid not the nodes but the empty-looking gaps users read as breathing room, so the canvas feels volumetric before any interaction. During a camera pan the shoal pushes against the pan direction, making the field look suspended in glass rather than pinned to the graph. Selecting a node leaves a temporary V-shaped hole that slowly refills from the edges, so focus itself leaves a wake.
