Design language (fixed): "A HUD, not a magazine" — ink-blue black #05070e, neon cyan / magenta / electric yellow, self-hosted Electrolize / Inter / JetBrains Mono, sharp corners with one notched edge, corner brackets on focus, circuit grid + scanlines, per-source neon hue via `--dn-src`.

PERF LAW: phones run ZERO animations; desktop at most 3 ambient loops per page; `prefers-reduced-motion` renders every spark's static end-state.

## Perf & motion budget

**1. Traceback Bus** — loop slot: none (event-driven). Phones: Static breadcrumb bar with all segments pre-etched at full var(--dn-src) and the terminal pad glowing; no probe, no counter ticks. Reduced motion: Bus renders permanently etched to the current pad with a static glowing probe parked on the deepest crumb; no travel, no counter animation.

**2. Tape-Head Reading Spine** — loop slot: none (event-driven). Phones: Strip is removed; the breadcrumb bar's last segment gains a 2px neon fill whose width equals the current page's cumulative reading-time percentage, static. Reduced motion: Canvas paints once with the tape-head parked on the current node, chip renders the title in full immediately, neighbor bloom never runs, strip stays fully legible.

**3. Strata Breadcrumb Compressor** — loop slot: none (event-driven). Phones: Renders as a static wrapping breadcrumb text row with the notch corners and per-source hue rule; `--w` is never computed and no stack overlay appears (direct navigation instead). Reduced motion: `--w` is pinned to equal shares and `--expand` stays 1, so the full breadcrumb labels are always visible in a plain row with no compression or transition.

**4. Provenance Trace** — loop slot: none (one-shot). Phones: Renders the frozen end-state immediately on mount: full rail, all nodes lit, brackets seated — zero rAF, zero dash animation. Reduced motion: prefers-reduced-motion skips the rAF entirely and paints the completed lattice with halo alpha 0.6 and brackets already at ±5px in one drawImage-equivalent pass.

**5. Deep-Link Landing Beacon** — loop slot: none (one-shot). Phones: The heading appears with its static corner bracket and the breadcrumb already updated, with no line or motion. Reduced motion: The beacon line is omitted entirely; the bracket and breadcrumb text appear instantly in their final positions.

**6. Spool Rewind Breadcrumb** — loop slot: none (event-driven). Phones: Static crumb row with the two spool arcs rendered at rest as a decorative glyph; tapping a crumb jumps instantly, no hold gesture. Reduced motion: The spool and ticks render frozen at their midpoint, rail is a plain crumb list, and a tap commits the scroll jump in a single frame with zero tween.

**7. Tether Drop** — loop slot: none (one-shot). Phones: Wire and stagger are skipped; the breadcrumb set and GRID REF stamp render already-complete with the persistent 1px left tick. Reduced motion: Full end-state on first paint: crumbs in place, stamp visible, tick present, no wire, no scaling.

## Why it surprises

**Traceback Bus** — A 4-deep page visibly carries a longer lit bus than a 2-deep page, so the breadcrumb silently doubles as a depth gauge you can read at a glance without reading a single word. The probe travels BACKWARD — pointer motion feels like rewinding a tape rather than hovering a link — and the mono counter de-counts in sync, turning 'go up one level' into a felt mechanical action. Most trails are decorative; this one is a measuring instrument, and where the probe stalls tells you the relative graph weight of any ancestor.

**Tape-Head Reading Spine** — Every minimap you've seen maps topology; this one maps time — position is minutes-into-the-docs, so a reader can feel that chapter 4 is 38 minutes deep without opening it. Scrubbing doesn't navigate, it only pretends to, until you click: the tape-head is a preview instrument, not a scrollbar. And the neighbor bloom is a nebula that exists only under your cursor, collapsing the way a torch beam reveals rock only where it lands.

**Strata Breadcrumb Compressor** — Breadcrumbs are the most inert element in any docs UI, and this one turns them into a quantitative readout: their widths encode how deep you've drilled, so the nav bar doubles as a depth gauge you can read at a glance. The inversion is the hook — instead of growing context as you go deeper, the trail *shrinks* toward its origin, which feels like descending a shaft rather than reading a page. And the two-stage stratum click means the breadcrumb can preview sibling space before committing, which no one expects a crumb to do.

**Provenance Trace** — The breadcrumb you normally ignore gets promoted to a physical cable that is *burned in* at the exact moment you arrive — then the canvas deletes itself and the mark lives on as a CSS pseudo-element on the heading, so the 'deep link' becomes a permanent notch in the page rather than a transient toast. It also derives the wire's length and hop count from the URL path depth, so a 4-segment deep link visibly unspools a longer, slower filament than a 2-segment one — the URL itself is the timeline. Unlike a breadcrumb bar, it never shows text labels; the shape alone tells you how far down the graph you landed.

**Deep-Link Landing Beacon** — It treats a URL hash as a landing vector with a route around text, not a dumb scroll jump. The line disappears into a breadcrumb, so the wayfinding UI rewrites itself to explain where you are. A session flag keeps repeat reloads from feeling theatrical after the first landing.

**Spool Rewind Breadcrumb** — The breadcrumb stops being a list and becomes a mechanism — a tape head that spools backward through your session while you hold it, so leaving a page is a rewinding act rather than a click. Releasing mid-rewind lands you at a fractional scroll offset interpolated between two trail entries, which means you can drop into a document you never actually visited at that depth. The spool only exists while your finger is down; the instant you let go it collapses back into ordinary crumbs, which makes the whole thing feel like a briefly visible machine hidden inside the HUD.

**Tether Drop** — The breadcrumb doesn't appear beside the journey — it is threaded onto the descent wire, so the URL fragment literally becomes the string the crumbs hang from. The wire then retracts upward and leaves a 1px scar that is quietly the copy-permalink hit target, teaching the affordance without a label. Deep-link landing is usually the least-designed moment in a doc graph; here it's the only place the HUD admits you arrived from somewhere else.
